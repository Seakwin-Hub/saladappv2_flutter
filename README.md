# 📱 Salad Detection App (Flutter)

> Flutter Salad Detection App. You can using this app to see Salad and Disease Image and Read the Disease Treament that i have research. The app can using image or open camera to take a photo to make Detection and Find the Disease for Salad.

## Features

- Detection Disease by upload Image or Take a photo and using Image Compression Flutter (package) to compress size of image.
- Display Salad and Disease general research.
- Dark Mode and Restful API (Python Flask).
- Handle Server error and Internet Connectoin using Connectivity Plus (package)
- Clean architecture with GetX (Dependencies Injection, Translation, Manage Routing, etc.) and Share Preference for local data.

- In This Screen the app have 4 buttons ("ថតរូបភាព", "ជ្រើសរើសរូបភាព", "ម្តងទៀត", "ធ្វើការស្វែងរកជំងឺ").

- "ជ្រើសរើសរូបភាព" It will open the gallery on your device to find a salad photo that you want to know it good heathy or have a disease.

- "ជ្រើសរើសរូបភាព" It will try to find disease for you when the image it correct (salad image) and it will come back with the name of disease, description and treatment as you see at image 4 and 5.
